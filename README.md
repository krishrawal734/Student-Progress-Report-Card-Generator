# Student Form Generator
[Live Demo](https://student-form-generater.netlify.app/)  

A simple and intuitive web application built with **HTML**, **CSS**, and **JavaScript** that allows users (teachers, administrators, or students) to dynamically generate and submit student registration or information forms. The app is deployed on Netlify and uses its form-handling capabilities to collect submissions.
---

## 🧰 Features

- **Dynamic Form Building**: Easily enter student details such as name, class, age, contact, and other fields.  
- **Validation**: Real-time input validation — required fields, correct data types, and more.  
- **Responsive UI**: A clean, mobile-friendly layout that works smoothly across devices.  
- **Form Submission**: Submissions are handled via Netlify forms, so no backend server is needed.  
- **Reset / Clear**: Option to clear the form and start afresh any time.  
- **User Feedback**: Display a success message or confirmation when the form is successfully submitted.

---

## 🚀 Why This Project

This project is useful for:  
- **Schools & Teachers**: Collect registration or student data easily without building a full backend.  
- **Small Educational Projects**: An efficient way to prototype or deploy student onboarding tools.  
- **Learning Web Dev**: Demonstrates form handling, validation, and client-side JavaScript logic.  
- **Portfolio Project**: A clean example of a static site with interactivity and form processing.

---

## 💻 Tech Stack

- **HTML5** – to structure the form and page layout.  
- **CSS3** – for styling, layout, and responsiveness.  
- **JavaScript** – for dynamic form behavior, validation, and DOM manipulation.  
- **Netlify** – for hosting and form submission handling.
